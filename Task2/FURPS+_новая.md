| Код    | Требования                                                                                                                                                | Комментарий                                                                                                                            |
|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------|
| **F**  | **Функциональные (Functionality)**                                                                                                                        |                                                                                                                                        |
| F1     | Отображение депозитов на сайте. Потенциальный клиент видит список депозитов с актуальными ставками.                                                       |                                                                                                                                        |
| F2     | Подача заявки с сайта. Клиент оставляет Ф.И.О. и номер телефона для обратного звонка.                                                                     |                                                                                                                                        |
| F3     | Отображение депозитов в Интернет-банке. Авторизованный клиент видит общий и персонализированный список депозитов с ставками.                              |                                                                                                                                        |
| F4     | Подача заявки в Интернет-банк. Клиент указывает счет-источник и сумму, подтверждает операцию SMS-кодом.                                                   |                                                                                                                                        |
| F5     | Управление ставками. Сотрудники бэк-офиса (депозиты и кредиты) должны иметь возможность управлять ставками по депозитам.                                  |                                                                                                                                        |
| F6     | Обработка заявок бэк-офисом. В MVP менеджер бэк-офиса подтверждает заявку и открывает депозит в АБС.                                                      |                                                                                                                                        |
| F7     | Оповещение клиента. Клиент получает SMS-уведомление о подтверждении ставки и об открытии депозита.                                                        |                                                                                                                                        |
| **U**  | **Удобство использования (Usability)**                                                                                                                    |                                                                                                                                        |
| U1     | Единый дизайн. Интерфейсы сайта и Интернет-банка должны соответствовать утвержденной в компании системе дизайна (brand book).                             |                                                                                                                                        |
| U2     | Минимизация шагов. Процесс подачи заявки должен быть максимально простым и состоять из минимального числа шагов.                                          |                                                                                                                                        |
| **R**  | **Надёжность (Reliability)**                                                                                                                              |                                                                                                                                        |
| R1     | Доступность всех сервисов на 99.9%                                                                                                                        |                                                                                                                                        |
| R2     | Устойчивость к сбоям АБС. Прямые вызовы API АБС из онлайн-каналов должны быть минимизированы, чтобы сбои/нагрузка на АБС не влияли на клиентские сервисы. |                                                                                                                                        |
| R3     | Горизонтальное масштабирование. Интернет-банк и новые сервисы должны масштабироваться горизонтально.                                                      |                                                                                                                                        |
| **P**  | **Производительность (Performance)**                                                                                                                      |                                                                                                                                        |
| P1     | Низкая задержка. Отклик по операциям в интернет-банке должен быть в миллисекундах.                                                                        |                                                                                                                                        |
| **S**  | **Поддерживаемость (Supportability)**                                                                                                                     |                                                                                                                                        |
| S1     | Использование существующих технологий. Предпочтение отдается MS SQL, Oracle, технологиям, по которым есть экспертиза (.NET, Java).                        |                                                                                                                                        |
| S2     | Документация. Необходимо предусмотреть разработку документации для дальнейшего расширения системы.                                                        |                                                                                                                                        |
| S3     | Совместимость с текущей платформой Интернет-Банка. Текущая версия платформы Интернет-Банка (.NET Framework 4.5) несовместима с Kafka.                     |                                                                                                                                        |
| **+R** | **+ Ограничения**                                                                                                                                         |                                                                                                                                        |
| +R1    | Защита данных. Передача чувствительных данных (персональные данные, номера счетов) должна быть защищена механизмом шифрования трафика (TLS).              | Требование безопасности                                                                                                                |
| +R2    | Избежание доработок ядра Интернет-Банка подрядчиком. Реализацию SMS-подтверждения предпочтительно сделать силами команды банка.                           | Влияет на распределение работ и выбор решений. Можно реализовать отдельным сервисом.                                                   |
| +R3    | Интеграция с Legacy. Новые сервисы должны интегрироваться с существующими системами: АБС, Система кол-центра, СМС-шлюз.                                   | Определяет контуры интеграции и необходимость создания адаптеров для систем с закрытыми или устаревшими API (например, АБС на Delphi). |
| +R4    | API для сайта и Интернет-Банка. Необходимо предоставить единый API для получения списка депозитов и подачи заявок как для сайта, так и для ИБ.            | Позволяет унифицировать логику и изолировать клиентские приложения от бизнес-логики.                                                   |
| +R5    | Мониторинг. Все новые сервисы и интеграции должны предоставлять метрики для мониторинга производительности и доступности.                                 |                                                                                                                                        | 
| +R6    | Выбор брокера сообщений. Для асинхронного взаимодействия предпочтительна Kafka "на перспективу".                                                          | Влияет на выбор технологического стека                                                                                                 |
